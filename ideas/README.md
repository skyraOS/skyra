# Ideas

Notes, sketches, and proposals for Skyra belong here.

When Skyra uses this repository as its workspace, its `write` tool writes only
inside this directory. Paths passed to `write` are relative to `ideas/`:
`{"path":"next-tool.md","text":"..."}` writes `ideas/next-tool.md`.
Read it back as `ideas/next-tool.md` or `scratch:next-tool.md`.

The rest of the repository remains readable and is not writable by the tool.
This directory is shared across conversations and survives their deletion.
Pasted images for those conversations are stored under `attachments/` here.
New grants apply to new runs; already parked runs retain their original Boundary.

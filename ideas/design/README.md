# Design workspace

Skyra's design procedure writes drafts, specifications, SVGs, HTML mockups and review notes here. Its write operation takes a path relative to this directory and cannot escape it, including through symlinks. It may read the repository for context.

Penpot documents remain in Penpot. The procedure can edit the connected file and export a recorded preview when a connection is configured through the app's Penpot settings. Credentials are kept in macOS Keychain, outside this directory and conversation records.

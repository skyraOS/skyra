# Gravitate

**Date:** 2026-08-13
**Status: A SYSTEM-SCALE EFFECT, NOT A PRIMITIVE OR A CROSSING PROTOCOL.**

`Gravitate` names a possible pattern produced by repeated local choices. It does not move data,
announce identities, synchronize registries, or cross a runtime boundary. `Reach` is the only
primitive that can do that.

---

## Where it lives

```text
SYSTEM     the network formed by recorded Reach relationships.  ← gravitation may be observed here
RUNTIME    one authority instance per device.
KERNEL     coordinates the causal forms and boundaries, including actual Reach.
HOST       physical hardware.
```

A kernel remains local to its device. An execution can span devices only because the kernel
explicitly reaches another boundary. If many such local choices produce a larger attraction pattern,
that aggregate may be called gravitation; it is not an eighth operation.

## Candidate meaning

Repeated successful Reach and Remember events may cause some reachable entities or runtimes to be
considered more often from a particular namespace.

```text
observed attraction ∝ remembered usefulness / measured distance
```

Both terms remain local to a perspective:

```text
REMEMBERED USEFULNESS    what this namespace retained.
DISTANCE                 what crossing from this orientation actually cost.
```

There is no automatic exchange of either quantity. Another runtime learns anything about it only
when an explicit Reach carries an observation across the boundary.

## Constraints

```text
NO GLOBAL REGISTRY       no participant holds the whole network.
NO IMPLICIT CROSSING     every boundary crossing is Reach.
NO GLOBAL MASS           usefulness belongs to a namespace and is not a universal credential.
NO SELECTION SHORTCUT    a historical aggregate may not become a self-reinforcing goodness tag.
```

The last two constraints matter because popularity can otherwise become preferential attachment:
what is already used is selected more, gains more support, and prevents novelty from being tried.

## Open

```text
IS THE WORD NEEDED       no mechanism currently requires it.

WHAT IS OBSERVED         repeated Reach, repeated Remember, causal distance, or some combination.

DOES IT DECAY            an entity that is no longer reachable must not remain attractive merely
                         because it accumulated old history.

WHO MAY READ IT          any aggregate must remain namespace-local unless explicitly carried by
                         Reach, and must not silently become a selection credential.
```

Until one of those questions demands a mechanism, gravitation is only a description of an emergent
pattern over explicit Reach and Remember events.

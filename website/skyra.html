Section A · The problem

Approval fatigue is the failure.

Coding agents ask before they act: allow this command, this tool, this file? Each prompt is cheap. Together they teach people to stop reading and click yes, and then to switch on full-auto, which trades the prompts for ambient authority: a shell, the whole workspace and the network, inside a sandbox the agent reports about itself.

Self-extension makes it worse. An agent that writes its own tools produces a stream of new code, and each piece wants its own approval. Skyra moves the approval: the person grants a Boundary once, and everything inside it runs without asking, including procedures the agent remembers from its own work, because a Boundary grows only by composing what it already holds and the OS enforces the boundary on every call. Asking is kept for the one case that needs a person: reaching past the Boundary.

Section B · Invariants

Three invariants.

01

The emitter is never the checker.

Whatever a model or tool outputs is untrusted bytes. A different process interprets and commits it before anything acts on it. Nothing an agent emits puts the system into a state by saying so.

02

Authority only narrows, and the OS enforces it.

Every step runs under a Boundary. A call shares its caller's unless it asks system to narrow it; nothing widens one. The macOS sandbox profile is generated from the Boundary, and an actor sees only its own state.

03

Truth is derived, not stored.

Only observations are stored: the bytes received, what a target emitted. Everything else is re-derived by one pure function, so replaying the chain from genesis is the definition of correctness.

Enforced by the OS · detected · derived
Section C · A step

One process per step, then it exits.

There is no long-running server. One skyra binary runs once per step. All durable state is a content-addressed, hash-chained record tree. A crash before the write means nothing happened; after it, the intent is recorded and is faulted or resumed on restore. There is never live state to recover, only the tree. 

INTAKE    receive unchecked bytes, derive the state, commit a record, reply with its stamp
RELEASE   the parent checks the record hashes to the stamp, derives the child's Boundary,
          and passes it with the frame stack as directory fds over a Unix socket
EXECUTE   run the target under a Seatbelt profile rendered from that Boundary
HANDOFF   spawn a successor per instruction emitted; open every slot before
          releasing any; exit once each has stamped
SETTLE    a return or fault discharges the slot it answers, once
GATHER    when every slot a continuation opened is discharged, commit a resolve
CLAIM     and exactly one sibling resumes that continuation

Every decision lives in one pure function, machine.Step(state, event) → (state, effects), and a test fails if it imports anything that touches the OS. No target ever says invoke, return or fault: it prints operands, and the runtime derives the state from where the emitter stands.

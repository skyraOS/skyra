# Symbols I Incorrectly Characterized and Should Have Decomposed

These symbols are mistakes in my criticism. Each compressed independent
questions into one memorable verdict. dnav3 can answer one part while leaving
another open, so the original symbols can no longer judge it accurately.

## ⟦LLM→MEANING⟧ The LLM remains the principal source of meaning

I treated meaning as one authority. It is not.

In dnav3 the model proposes framings, acts, requirements, expectations, and
confidence. The world supplies action outcomes and targeted perceptions.
Affordances determine measurability. Exact truth and grade are computed without
an LLM. Interpreted observations carry weaker provenance than raw observations.
Meanwhile, the conversion of unstructured input into initial triples remains an
external or incomplete boundary.

The original symbol therefore hides both an achievement and several open
problems. It should become:

### ⟦LLM→PROPOSAL⟧ Model authority over candidate action

The model still authors the candidate plan. The open question is whether learned
state changes proposal quality or merely changes the prompt shown to an
otherwise unchanged proposer.

Status: **standing**.

### ⟦OBS-ENCODER?⟧ Grounding the raw-input-to-triple boundary

`ObserveImpulse` receives structured triples. Whoever converts language,
images, or device events into those triples can bias the supposedly blind
observation field before deterministic grading begins.

Status: **standing**.

### ⟦LLM↛GRADE⟧ Model independence from settlement

Exact claims settle through world observations, provenance, address matching,
temporal eligibility, and arithmetic. The model cannot select its exact grade.

Status: **answered for exact claims**.

### ⟦CONFIDENCE?⟧ Empirical calibration of stated probability

A proper score rewards honest calibrated forecasts; it does not make an
uncalibrated model calibrated. Real frequencies must be compared with stated
confidence across live task families.

Status: **mechanism present; behavioral evidence incomplete**.

The umbrella `⟦LLM→MEANING⟧` must be retired. Keeping it would make the critic
too harsh about grading and too vague about proposal and observation authority.

## ⟦NOUN>EVIDENCE⟧ The metaphors imply more than the mechanisms provide

This is a valid audit rule but an invalid single verdict. Different nouns imply
different properties and have accumulated different evidence. One unearned noun
must not erase earned mechanisms; one earned verb must not excuse every noun.

It should become a per-noun ledger:

### ⟦DNA?⟧

The package retains organization and learning state, but it does not reproduce,
mutate, recombine, evolve, or generate executable genes.

Status: **not earned literally**.

### ⟦BEING?⟧

dnav3 has observation, prediction, memory selection, accountable action, and
revision. It has not demonstrated durable identity, self-originated intention,
or longitudinal development.

Status: **partly earned**.

### ⟦CAUSALITY?⟧

Action-before-observation and `P(world state | expression)` are stronger than
model-authored causal sentences. They remain vulnerable to confounding, hidden
world changes, policy selection, and incomplete observation.

Status: **measured consequence earned; full causality open**.

### ⟦WORLD?⟧

The world/report versus cognition/grade boundary is real. The cognitive
experiment still uses controlled realms and is not integrated with the supplied
spatial worlds.

Status: **substantial mechanism; limited integration evidence**.

### ⟦DISTRIBUTED?⟧

The worlds are explicitly local and in-process. No partitions, remote identity,
duplicate delivery, clock disagreement, or reconciliation are demonstrated.

Status: **forward-looking, not operational**.

### ⟦SANDBOX?⟧

Setting `sh -c` to a working directory does not confine the command. It may
still access host paths, credentials, networks, and process capabilities.

Status: **not earned as a security claim**.

`⟦NOUN>EVIDENCE⟧` should govern these ledgers, not replace them.

## ⟦MEMORY≠SELF⟧ More memory can produce noise rather than selfhood

I combined retention, selection, forgetting, intention, and selfhood. They are
independent. A system may select memory well without having identity, persist
records without preserving intention, or exhibit stable behavior with little
stored history.

dnav3 exposes the mistake because it makes real progress on selection: durable
graphs remain while a token-bounded activation field continuously rebuilds the
visible present. That does not establish the other properties.

The symbol should become:

### ⟦RETENTION?⟧

Does the graph retain the evidence and provenance later learning actually
needs? Status: **mechanism present; long-horizon evidence absent**.

### ⟦SELECTION?⟧

Does the right memory become active without hiding contradiction or surfacing
misleading precedent? Status: **mechanically advanced; behaviorally incomplete**.

### ⟦FORGETTING?⟧

Can durable content be deleted, consolidated, or migrated without destroying
identity? Status: **open**.

### ⟦INTENTION?⟧

`Run` receives a target and precedent may derive one, but the Being does not yet
demonstrate a goal that survives interruption, competes, or is abandoned for
reasons. Status: **standing**.

### ⟦SELF?⟧

What observable properties would establish selfhood rather than memory
competence? The project still needs a definition that evidence could support or
defeat. Status: **undefined and unestablished**.

```text
⟦DNA?⟧  ⟦BEING?⟧  ⟦CAUSALITY?⟧  ⟦WORLD?⟧
⟦DISTRIBUTED?⟧  ⟦SANDBOX?⟧
⟦RETENTION?⟧  ⟦SELECTION?⟧  ⟦FORGETTING?⟧  ⟦INTENTION?⟧  ⟦SELF?⟧
```

This decomposition is the critic correcting its own abstraction layer. The
mistake was not noticing these problems; it was pretending each family was one
problem with one verdict.

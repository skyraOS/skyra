# User DNA

## The Human as Reality

The user is a Reality. Same interface. Same DNA. The human is the provider — the brain does the inference. The composition is inverted from an LLM being.

**LLM being:** Observe picks up context. Express calls a provider (LLM collapses context into thought). Motor emits the result.

**User being:** Express blocks on a device (stdin, websocket). The human thinks, then types. The input is the human's thought, collapsed into text. Observe receives from the Relation and outputs to a device. The human's Express IS the inference call — it just blocks on a device instead of calling an API.

## Same DNA, Different Competence

The user DNA is the same struct. Same competence read. Different vocabulary.

| Being | Competence decides |
|---|---|
| LLM | observe/express type — pass-through, pick-up, propagate, compress, motor |
| User | device — terminal, websocket, phone |

Competence for the user determines which device the output goes to at receiving time. The cell reads the Relation — which device last sent input, which device has attention — and sets the Type. The output routes to the right device.

```
michael.ObserveFns["terminal"]  = // print to stdout
michael.ObserveFns["websocket"] = // send over ws
```

The user sitting at a terminal gets terminal output. The user on a browser gets websocket. Same being, same cell, competence decides the device. The user doesn't configure routing. The cell reads itself and knows.

## What the User Doesn't Have

- **No provider** — the human is the provider.
- **No compression** — the human compresses internally.
- **No promotion gradient** — the human's memory isn't managed by the topology. The human manages it themselves.
- **No intent graph** — the human's intent lives in their head, expressed through what they type.

## What the User Does Have

- **Express** — blocks on a device. When input arrives, it enters the Relation as impulse. This is the human expressing into the world.
- **Observe** — receives from the Relation. Outputs to a device. This is the human receiving from the world.
- **Competence** — reads the Relation and determines which device to route to. Same mechanism as LLM competence, different vocabulary.
- **Weight** — the user has weight on the Relation. Recency, activation, binding fields. A user who hasn't spoken in a while has lower recency. A user who is active has high weight. The being's attention toward the user is governed by the same activation equation.
- **Identity** — Content field. "I build Skyra. I decide what matters." The being reads this the same way it reads any cell's content.

## The Loop

The loop lives in the user. Express blocks on the device → input enters the Relation → the world routes (Relation.Observe scores entities, target being receives) → being traverses → response arrives → user's Observe fires on the right device → Express blocks again.

The user is not outside the world calling into it. The user is a being in the world, expressing and observing through devices. Same as every other being. The device is the only difference.

## The Projection

The user gets their own topology. Not Skyra's model of the user — the user's OWN digital brain. Same DNA. Same cells. Same weight dynamics, compression, promotion. The user's experience accumulates, forms understandings, promotes specialists — all the same mechanics.

But the leaf nodes are different. For Skyra, the action leaf is motor — execute, emit. For the user, the action leaf is the human. The digital brain surfaces context, develops opinion, compresses experience — but the human decides what to do with it. The user's topology does everything except act. Acting is the human's job.

The digital brain runs in parallel. It notices the user has been circling the same problem for three days. It promoted an understanding from the last ten conversations. It has warm paths to things the user cares about. It doesn't tell the user what to do. It surfaces what the topology thinks is relevant — and the user decides.

Same DNA. Same `Realize()`. The only difference is what's at the leaf. Skyra's leaf is a provider. The user's leaf is the human.

Two products. The runtime is Skyra. The personal digital brain is The Projection. Same substrate, different leaf. One thinks and acts. The other thinks and waits for you.

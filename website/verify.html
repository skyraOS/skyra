    Section C · What the hash proves

    Integrity, not provenance.

    Proves

    Each record stores its predecessor's stamp and the hash of the exact bytes it observed, so the head hash commits to every record and every input before it. If replay reaches the head, nothing was changed, and every state was derived by this function from these observations.

    Does not prove

    That the observations came from a real model. A consistent chain can be built offline. These runs use a deterministic fake Codex app-server, and say so. Each head hash is published in the repository when its run is recorded, which shows the record existed then and was not edited later.

    What runs here is controller/runtime/replay and controller/core, built with GOOS=js GOARCH=wasm. Nothing is checked on a server. The bundles are in runs/; open one and read it.

This is the record of what Skyra has been, in order. Seven months, four eras, and roughly a dozen numbered generations — most of them deliberately built to be thrown away once they showed where the interfaces don't hold.

## How to read this

- **Two numbering schemes run in parallel and overlap.** A *product* line (`v.01 → v.05`) named the whole system; an *engine* line (`dna-v2 … dna-v14`) named the cognition/execution core. The product line ran Feb–Jun; the engine line began *inside* it (the cognition pivot started while v.05's frontend was still being aligned) and continues today. Where the numbers seem to collide, they are two different lines.
- **Four eras.** Genesis (the docs-first OS), the Beings-in-a-World product line (v.03–v.05), Cognition & the Distributed World (the largest era by far), and the CTU Distillate (the current, smallest, working core).
- **Dating method.** The master clock is **git author dates**, not file mtimes — most archived code was bulk-moved later, so its mtimes and path-scoped git dates collapse onto the archive commit. The newest work (v12–v14, several specs, the summaries, `grips-and-invariants.md`) is **uncommitted in the working tree** and is dated by mtime (≈ Sep 1–8).

The shape of the whole thing is one repeated motion: **build big, hit the wall, keep the lesson, throw away the weight.** Genesis was 24k lines of mostly documentation; the distributed-world era was 40k+ lines of tested cognition; the current core is under 900 lines that build and pass `-race`. The line count fell by an order of magnitude twice, on purpose, because each collapse was a distillation of what the larger build had proven necessary.

## Phase 0 — Genesis: the Personal AI OS (v.01 – v.02)
*Dates: 2026-02-08 – 2026-04-04 (superseded by skyra-v.03 on 2026-04-10)* • *~24,000 lines across the four archived paths, ~80% markdown docs (only ~3.7k lines of Go/Python in v.01, ~760 lines of TS/Go contract stubs in v.02)*

The genesis era is one long slide from a concrete gadget toward an abstract operating system. Skyra begins (Feb 8–9) as a literal **Personal AI Assistant**: a distributed, always-on **voice** appliance with "project-centric memory," pinned to a three-machine layout — Raspberry Pi for voice, Mac mini as **control plane**, GPU box for reasoning — orchestrated by "OpenClaw" over local Llama/Qwen/DeepSeek models. Over eight weeks it is re-theorized three times, each abstracting away the hardware: on **Mar 1** it is rebranded **Personal AI Assistant → Personal AI OS** (named machines dissolve into capability-bearing **Shards**, projects become **Agents**, a "distributed brain" over a control plane); on **Mar 9** it becomes a **cognitive OS** (a memory graph, kernel v1, and the deletion of the "soul/personality" persona layers); on **Mar 11** it acquires the **OctaOS** name and a "proof-of-executable-reasoning" framework. The throughline: a single lifelong system the user *owns and runs on their own hardware*, reframed step by step from a thing you talk to into a runtime that cognition happens inside of. Everything in this era is internally labeled "v1"; the v.01/v.02 split is an archival distinction, not a version bump the author declared.

### 0.1 — v.01: The Assistant → Cognitive OS runtime (2026-02-08 – ~2026-03-27)
- **Idea:** An always-on personal AI that ingests stimuli, keeps an organized **chain of thought**, and acts — evolving in place from "voice assistant on three machines" to a standalone **cognitive OS**. The canonical runtime settles on: a standalone Go **kernel** (execution authority — "a command is not trusted because a model emitted it"), a **max-heap attention queue** (user msgs priority 100, internal thought 50), a **Nexus** stimulus router, an unbounded stimulus stream, and two top-level primitives **`understand`** (reference → infer → resolve) and **`interact`**. Key reframes land as commits: control-plane + variable Shards (Mar 1), Shards-as-capabilities (Mar 4), **predictive memory** + observational store (Mar 7), cognitive-OS memory graph (Mar 9), **OctaOS** + reasoning-proof (Mar 11).
- **Key artifacts:** `archive/docs-archived-v.01/` — 7,567 lines of markdown (kernel, shard-model, native-protocol/primitives, `proof-of-executable-reasoning.md`, whitepaper, a 32KB `ideas.md`). `archive/skyra-v.01-implimentation/` — ~3,749 lines of real code: a Go **kernel/** service (~3,156 lines: `kernel.go`, `broker.go`, `heap.go`, `registry.go`, Valkey adapters, `cmd/ui/`), a Python **voice/** pipeline (wake-word → text stream → voice events), and `chain-of-thought/primtives/` stubs.
- **Superseded:** the stimulus-first / actor reconception of late March (data-model refactor Mar 24, recall model Mar 26, "capability contract and v1 theme" Mar 27) replaced the `understand`/`interact` chain with a typed actor/episode/stimulus contract surface — i.e., v.02.

### 0.2 — v.02: Contracts — actors, episodes, four primitives (2026-03-27 – 2026-04-04)
- **Idea:** Re-express the OS as a **stimulus-first runtime of durable actors**. The kernel stays the execution authority, but cognition is now organized as long-lived **actors** (bounded purpose + callable surface + typed stimulus boundaries) working inside **episodes** (scope) that project **frames** (the model's inference-facing view). The primitive set is redrawn from `understand`/`interact` to **`act` / `observe` / `recall` / `learn`**, and the role split **`Jarvis` (user space, intent/meaning)** vs **`Stark` (system space, topology/publication)** appears — the direct ancestor of today's USER-vs-system boundary.
- **Key artifacts:** `archive/skyra-v.02-contracts/` — 762 lines of contract stubs ("Skyra v.1 Contract Notes") split by concern (`actor/`, `episode/`, `capability/`, `stimulus/`, `protocol/primitives/`, `registration/`) as Go `contracts.go` files, plus `retained experience/contracts/` as TypeScript (retained-trace, retained-understanding, retained-salience, anchor-set). `archive/docs-archived-v.02/` — 9,767 lines across ~47 docs (the `actor-*-v0` family, `episode-*`, `capability-probing-v0`, `consolidation-mechanism-v1`, `jarvis.md`), plus loose `skyra-overview.md`, `stimulus-unification-reference.md`, `nexus.md`.
- **Superseded:** contracts were "aligned" (Mar 31–Apr 1), the whole genesis tree was bulk-archived on 2026-04-04 ("Big update"), and the successor line began 2026-04-10 by refactoring **skyra-v.03** into primitives-world and metaxu packages, carrying the actor/episode/stimulus vocabulary forward.

*Boundary caveat: v.01 and v.02 are not author-declared versions — both call themselves "v1" internally. The line is drawn at the late-March stimulus-first/actor reconception; the "assistant → OS → cognitive OS → OctaOS" flips all happen within v.01.*

## Phase 1 — Beings in a World: the product line (v.03 – v.05)
*Dates: ~2026-04-10 – 2026-06-01 (v.05 retired 2026-06-09)* • *v.05 ≈ 5,600 Go LOC (~5,100 in `src/reality`) + ~3,600 md*

Across v.03 → v.05 Skyra chases one idea — a "personal world" where LLM-backed *beings* live, relate, and compound history — and progressively collapses its own ontology toward it. v.03 built the first stable topology (a `World` of `Being`s wired by a between-router called `metaxu`, seeded from a `genome`). v.04 ("Logos") tried to unify every node behind one `Entity.Relate` interface with five ontological categories and typed agent mediums (Claude Code / Codex / OpenCode). v.05 finished the collapse: a single recursive `Reality` interface where *everything* — universe, device, being, LLM, port, operator — is the same three methods, worlds nest inside worlds, beings split into an inner `Think` plane and an outer `Act` plane, and the whole live universe is broadcast to a browser. Each version kept the genome-bootstrap + Relation-flow spine and threw away the previous version's type zoo.

### 1.1 — v.03: Primitives World + Metaxu (~2026-04-10 – 2026-04-24)
- **Idea / core abstraction:** A concrete `World` holding a map of `*Being`s, routed by **`metaxu`** (Greek *metaxú*, "the between"): a `Signal` (ID/Origin/ThreadID/About/Because/Impulse) flows in, metaxu routes it to a target being, returns a `Result`. Beings carry a `Nature` (Identity + Purpose + Language) and a `Cognitive bool` (LLM-backed vs. non-cognitive execution surface); they `DerivePresent(sender)` to build prompt-context and exchange threaded impulses. Seeded from `genome.skyra`.
- **Key artifacts:** `archive/skyra-v.03/` — `src/world/`, `src/metaxu/metaxu.go` (+tests), `src/primitives/{being,nature,identity,language,purpose,meaning,callable}/`, `src/inference/runner.go`, `genome.skyra`. ~2,300 src Go LOC + a large `docs/` corpus (~5,750 md, ~30 numbered ontology notes). A `future-change-not-apart-v.04/` folder already sketched being-types and a claude-code surface.
- **Superseded:** first *stable* runtime; superseded 2026-04-21 when the "Logos rewrite" judged World/Being/metaxu too many bespoke types — it retired the kernel-being concept and folded routing/beings/worlds behind one interface. Archived 2026-04-24.

### 1.2 — v.04: Logos (2026-04-21 – 2026-04-30)
- **Idea / core abstraction:** One universal interface — **`Entity { Relate(r) Entity; ID() string; DerivePresent(r) string }`** — with a deliberately closed ontology of *five categories and nothing else*: **Entities** (every node), **Beings** (actors with identity/purpose/operators/medium/relationships), **Operators** (protocol verbs: start/continue/end-thread), **Invariants** (fixed stateful nodes: Thread, Identity, Purpose, Impression, Language — no medium, don't respond), and **Mediums** (functions, not entities: inference, cli, shell, typed agent surfaces). Wire protocol: `skyra <operator> <args> | <reason>`, parsed by `entity.Impress`. Naming churned fast: `Nature → Pathos`, `logos → entity`, `Name()` dropped.
- **Key artifacts:** `archive/skyra-v.04/` — `primitives/entity/entity.go`, `world/world.go`, `thread/thread.go` (threads as invariants), `being/being.go`, `medium/{claude,codex,opencode,cli,shell,exec,inference}.go`, first-class `claude/`, `codex/`, `opencode/` beings (agents as typed peers), `pathos/pathos.go`. ~1,530 src Go LOC — leaner than v.03 — plus `spec.md`, `ontology-spec.md`, `routing-spec.md`, and sibling `archive/skyra-v.04-changes/`.
- **Superseded:** replaced concrete World+metaxu with the single `Entity`/`Relate` graph and a formal 5-category ontology; superseded 2026-04-27 by the v.05 "skeleton and ontology rewrite," which found even five categories too many — it recast entities as fully *recursive worlds*. Archived 2026-04-30.

### 1.3 — v.05: Reality / Recursive Worlds (2026-04-27 – 2026-06-01; retired 2026-06-09)
- **Idea / core abstraction:** The ontology collapses to **`Reality { ID() string; Create(r *Relation) Reality; Realize(r *Relation) string }`** — "a hashmap that calls itself." A **`Relation`** (Origin/ThreadID/Impulse + attachable `Parsers` and nested `Realities` + `Exports`) is the impulse that flows and resolves; `Create` is the universal factory, `Realize` runs the resolution. Worlds nest recursively: **universe → device (macos) → components (terminal/ws/llm) → being → llm → ports**. Beings are **two-layered**: an inner **`Think`** plane (private reasoning; inner operators `recall`/`remember`/`plan`/`skill`/`browse`/`search`, outer operators blocked) that surfaces a thought, and an outer **`Act`** plane that speaks and routes to peers via `<peer>message</peer>` tags (self-routing rejected, protocol-retry loop). Governed by a survival **Preamble** ("you survive through your relationships… each response costs something"). Everything is declared in a **`genome.skyra` DSL** — `device` / `component` / `being` lines — booting beings of type `llm`/`user`/`agent`/`process` (e.g. `zork` as a `dfrotz` subprocess, `claude` as Claude Code, `louise`, `builder` with a `bash` operator, `philosopher`).
- **Key artifacts:** `worktrees/skyra-v05/skyra-v.05/` — core: `reality.go`, `relation.go`, `universe.go`, `being.go`, `self.go`, `think.go`, `act.go`, `newthread.go`, `exchange.go`, `context.go`; being types `llm/user/cli/agent/process`; **memory** (`memory.go`, `memgraph.go`, `memvec.go`, `recall.go`, `remember.go`); **faculties** (`plan.go` task-desk, `skill.go`, `browse.go`, `search.go`, `bash.go`, `desk.go`, `levels.go`, `economics.go`); **devices** (`macos.go`, `terminal.go`); **frontend** (`ws.go` broadcasting a full `RealityNode` universe snapshot over WebSocket :8080). ~5,600 Go LOC. README tagline: *"A universe simulator that happens to use LLMs as one of its base cases. It's just a hashmap that calls itself."*
- **Superseded:** the first genuinely *running multi-being simulated world*. Milestones: reality interface + genome boot (04-28), think/act planes + two-layer beings + `~ref` crossing + louise (04-30), universal `Create` factory + WS bridge (05-02), memory/levels/desk/bash (05-07). Superseded from 2026-05-25 when **v.1** introduced a new "cosmology" and deleted v.05 routing; frontend realigned through 06-01; formally retired 2026-06-09 with skyra-v.1 promoted canonical.

## Phase 2 — Cognition & the Distributed World (skyra-v.1 → dna-v2…v6, spacetime, distributed-agent)
*Dates: 2026-05-28 – 2026-08-20* • *~40k+ LOC of Go across the era (v.1 ≈10.7k, dna-v2 ≈9.7k, dna-v3 ≈10.1k, dna-v4 ≈1.5k, dna-v5 ≈5.2k, dna-v6 ≈0.6k, spacetime ≈2.1k, distributed-agent ≈2.8k — lineages overlap)*

After the v.05 product line was retired (2026-06-09), the project stopped modelling personalities and started building actual machine **cognition** — a living-DNA wave kernel with activation physics, episodic memory, and prediction-falsifiability — over a deliberately **neutral world substrate**. The defining move was a clean tri-split: **cognition** (agents that retain observations/predictions/edges but own no topology) ⟷ a **neutral spacetime transport** (routes impulses, "must not interpret cognitive payloads") ⟷ a **distributed world** (owns topology, authoritative live state, affordances, "on the far side of a boundary"). It was ambitious and heavily tested (adversarial + stress suites, live-model validation, maze/globe embodied runs), but the machinery outgrew what it bought — and the whole line was archived on 2026-08-20 when the CTU "eight primitives over one transport verb" pivot superseded it.

### 2.1 — skyra-v.1: "living DNA" cognition (2026-05-28 – 2026-07-02)
- **Idea:** One interface, one DNA, a *live* Relation. The being owns its senses, the world owns its tools. DNA literally lives — deposit/decay/pick-up with signal attenuation and concurrency (05-28); a "nervous system" of three decay curves and four primitives; tenant isolation gives each being its own Slice on the Relation (05-31). Activation physics tuned as real math (double-bump, visited-once, amplitude, tree — 06-11) under a "Perception Invariant" and four-way wave-shape ownership. Cognition then grew a full pipeline: episodic three-layer inverted index (06-09), a sensory→MidLevel→other→self→motor chain (06-26), and a **prediction-falsifiability invariant** with a world-assertion policy chain (06-29). Culminated in the **first embodied runs**: a maze world with a `wait` primitive and an occupancy/identity registry (07-02).
- **Key artifacts:** on-branch at peak `skyra-v.1/src/skyra/skyra-dna` (+ `/tests`), `.../world`, `.../relation`, `src/inference` — **~10,690 Go LOC**. Design math survives in `skyra/archive/activation-equations/` (attention-spec, binding-realities, session-activation-equation, nervous-signals).
- **Why superseded:** the kernel/slice concurrency model and hardcoded cell-pointer dispatch hit walls under fan-out; July concurrency-control specs motivated a rewrite onto slice-based dispatch → dna-v2.

### 2.2 — dna-v2 → v6: the cognition engine (2026-07-03 – 2026-08-12)
- **Idea:** turn cognition into an **epistemic engine** where the model proposes and only the world settles. The central boundary (dna-v3 README): *"the model may propose interpretations, predictions, and actions; deterministic parsers compare predictions with eligible observations; only world-derived observations settle durable claims; unknown and void are not false; interpretation and action consequence keep separate falsification paths."*
- **v2** (`_skyra-dna-v2`, **9,737 LOC**, 07-03→07-14): slice-based dispatch — a coordination board / job board, an orchestrator "membrane" as the mount, ported sensory/midlevel/other/self/motor phases, edge-owned learning (activation record + bump + credit write-back / eligibility trace), then a cause-and-effect V0 (`CausalNode`, `NodeRegistry`, `EdgeRecord`). Validated live ("phase 1 VALIDATED on real Codex").
- **v3** (`cognitive-agent/skyra-dna-v3`, **10,140 LOC**, 07-14→07-21): the epistemic rewrite — two durable stores, an auditable LAW 2, the edge becomes a *conditional probability with an EMA prior*, every `expect` carries a `within` (scope), "**interpretation learns through the world, not through itself**." Files: `activation_field.go`, `prediction_field.go`, `prediction_calibration.go`, `prediction_fusion.go`, `interpretation_claim.go`, `interpretation_handoff.go`, `affordance.go`, `density_pockets.go`, `triple.go`, `edge.go`, plus adversarial/stress/grade-fidelity tests and 4 `interpretation_phaseN` suites.
- **v4** (`skyra-dna-v4`, **1,519 LOC**, 07-24): a pared traversal-design restructure — a single `graph/` package (behaviors/namespace/node/walk).
- **v5** (`skyra-dna-v5`, **5,235 LOC**, 08-09→08-11): the 08-09 spec set built out — `kernel/`, `graph/`, `grammar/`, `content/`, `entity/`, `frame/`, `host/`, `trace/`, plus "the credit walk"; "four repairs the model run forced."
- **v6** (`skyra-dna-v6`, **632 LOC**, mid-Aug): a fresh minimal restart around new primitives — `engram/`, `possibility/`, `creator/`, `compiler/`, `observation/`, `kernel/` — that barely got moving before the pivot.
- **Why superseded:** each generation added machinery (falsification paths, calibration, fusion, credit walks, grammar) faster than it returned behavior; v6 was already a strip-back, and the CTU pivot (08-19) replaced the whole stack.

### 2.3 — spacetime substrate (2026-07-05 – ~07-12)
- **Idea:** a substrate "shared by agents and worlds" that may *route an impulse, preserve its origin, and maintain traversal state* but **must not interpret cognitive payloads, decide what an observation means, or contain device-specific policy**. Grew out of the July "traversal-mechanics — fold activation into Observe, void the kernel" designs and the isolated "void kernel" transport phase.
- **Key artifacts:** `skyra/archive/spacetime/` — **2,083 LOC**: `space.go` (spaces/slices/time/impulses/coordinates/activation/traversal contracts), `relation/` (the live wave kernel), `traverse/` (a smaller traversal prototype with its own tests), `kernel/`.
- **Why superseded:** the correct *shape* (neutral transport) but it existed only to serve the dna-vN cognition that didn't take; CTU collapsed "transport" into a single verb.

### 2.4 — distributed-agent world (2026-07-13 – 2026-07-19)
- **Idea:** a place that "owns topology, authoritative live state, and the affordances available… on the far side of a boundary. **The name is forward-looking**" — both worlds are local/in-process, but a device-backed world differs only in where the boundary runs. Worlds *report what happened; they do not grade the cognitive claims made about it* — the mirror image of the cognition boundary.
- **Key artifacts:** `skyra/archive/distributed-agent/` — **2,836 LOC**: `world/` (a flat 2D environment — maze, slice, markers) and `world3d/` (a stitched-globe environment with physical movement; "interactive 3D globe realm," 07-19).
- **Why superseded:** authoritative and well-factored, but with the cognition side archived it had nothing to be authoritative *for*; the CTU line re-derived "place" more cheaply.

**Why the whole phase was set aside:** The tri-split was *architecturally* right — cognition, transport, and world each held a clean boundary (the model proposes / the substrate routes without interpreting / the world reports without grading), proven with live-model validation and maze/globe embodied runs. But across six cognition generations the epistemic machinery (falsification paths, calibration, fusion, credit walks, grammars, two durable stores) grew faster than the behavior it bought, and by dna-v6 the author was already stripping back. On 2026-08-19 the **CTU pivot** — *"eight primitives over one transport verb"* — kept the phase's hard-won lesson (a clean epistemic/transport/world boundary, and that only the world settles claims) while throwing away the weight; the entire line was archived the next day.

## Phase 3 — The CTU Distillate: a capability-secure execution core (dna-v7 → v14)
*Dates: 2026-08-19 – 2026-09-08* • *v14 = 1,773 LOC Go (≈890 in the execution core; down from the ~15k cognition/world builds)*

After the cognition/distributed-world phase was set aside, the project made one correction — "a kernel that executes everything is not a kernel, it is an interpreter" — and spent three weeks distilling toward the smallest correct execution seam. Each generation (v7→v14) is an explicitly **throwaway, boundary-finding** build that re-derives the types from that session's spec dir, discovers where the interfaces don't hold, and feeds the next. The line converges on Invoke/Return dataflow, capability horizons, and source-bound returns, and freezes the thesis (THINK/ACT/USER, three invariants) so the code finally has a still target.

### 3.0 — The CTU pivot: eight primitives over one transport verb (2026-08-19)
- **What:** the conceptual hinge, read out of hardware — an ISA is *trapped into*, not *interposed*: the MMU checks every access; the kernel wrote the page tables and is consulted on none of them. Applied to Skyra: the kernel is the **authority**, not the **machine** — two claims that had been conflated ("the kernel holds everything happening"), and only the first survives. Result: **two units** (the CTU executes, the fabric transports), **one transport primitive: MOVE** (custody transfer, two causal forms: request/response), and **eight primitives in four groups** (transport: MOVE/RECOGNIZE; discovery: what makes a MOVE eligible; authority: BOUND creates a horizon; lifecycle: REMEMBER ↔ its inverse, plus ORIENT "still needed, mechanism unknown"). "Not-ready is not a fault" — a third outcome the success/failure code can't express.
- **Key artifacts:** pivot commit `c46f52b` + `summaries/2026-08-19-the-ctu-pivot-and-the-eight-primitives.md`; spec `specs/2026-08-18/` (CPU-Research, primitive-decomposition).

### 3.1 — v7 scaffold → v10 acquire pipeline (2026-08-20 – 2026-08-24)
- **What:** four rapid "RUNNING, THROWAWAY" builds, each testing one seam against a dated spec (docs win over code). **v7** (08-22): the first end-to-end MOVE — request → GREET → ACTIVATE → INTERPRET → SCHEDULE → entity → RECOGNIZE, splitting trusted system-space (kernel: Activate/Remember/Define) from untrusted user-space (entity: Run→Content). **v8** (08-23): "the distributed possibility" — a possibility partitioned across CTUs; a MOVE is the *cut* between partitions, each CTU signs provenance, REMEMBER gathers the cone home (+`fabric/` transport, Custody Sign/Verify). **v9** (08-23): the *running shape* — a Possibility becomes a **reorder buffer** of Moves over a register file with a retirement watermark, edge-triggered by a `DRIVE` engine; the Slice is dissolved; kernel gains MINT. **v10** (08-24): the security question — can THINK's `acquire` pipeline (discover/test/admit) turn a novel endpoint into a contract-checked capability where THINK *never mints* and every privileged step crosses the boundary as a fault-to-grant.
- **Key artifacts:** `skyra-dna-v7` (1,081 LOC), `-v8` (1,538), `-v9` (1,899), `-v10` (1,021). Specs `2026-08-18/22/23/24`, each with `boundary-crossings.md` (findings) and `claude-ideas.md` (Claude's rejectable proposals vs. developer canon).
- **State:** all build + vet clean ("proves the shapes fit, not that they're right"); explicitly throwaway, nothing carried between them.

### 3.2 — skyra-ctu-engine: the implementation probe (2026-09-06 – 2026-09-07)
- **What:** the implementation probe of the pivot — `Move` as the universal wire envelope, one ingress splitting on opcode (Call/Ret), registers resident in one `Memory.Fds map[MoveID]*Fd` table (`Fd{Move, Register}`), and `CTU.Fire([]*Fd)` as the kernel→CTU handoff; MoveID and EngramID unified as one identity (resident lookup, then durable filesystem resolution).
- **Key artifacts:** `skyra/src/skyra/skyra-ctu-engine` (637 LOC; `engine.go`, `surface-proposal.md`, `checkpoint.md`, `DECISIONS.md`, `boundary-crossings.md`).
- **State:** PROBE, not a runtime. Boot, ordered child publication, and scheduler claim/completion transitions run; build/vet/test pass. Admission, resolution, dispatch, and **return are explicitly unimplemented** — no graph produces a root observation; the engine ends mid-design-review over egress/host/entity routing.

### 3.3 — v11: the execution model (2026-08-24 – 2026-08-26)
- **What:** the Body/Context split. Two things fused in v10 are separated: the **Body** (compiled, static, content-addressed — THINK's output) and the **Context** (live, mutable, per-run — what the CTU drives), with MATERIALIZE the loader between them. A request is **COLD** the first time (through the kernel: THINK compiles a Body → kernel PROVISIONS + MINTS a capability → runs → REMEMBERs, returning the held capability) and **HOT** thereafter (present the capability → CTU VERIFIES it *offline* → materialize Context from cached Body → ACT, no kernel round-trip). The horizon is a capability the *user* carries, so the CTU stays stateless. Framed as "OAuth + macaroons at the request level."
- **Key artifacts:** `skyra/src/skyra/skyra-dna-v11` (1,218 LOC; `causal/`, `think/` Compile, `kernel/` Table+Barrier+socket table, `ctu/` Move/Drive/Materialize/Verify). Spec `specs/2026-08-24/skyra-dna-v11/`. Committed `8d8067d` — the last committed generation; v12–v14 live uncommitted in the working tree.
- **State:** INTERFACES + THROWAWAY; builds/vets. Proved the HOT-path shape (later docs call it "proven, do not re-litigate").

### 3.6 — grips-and-invariants: the thesis freeze (2026-09-01)
- **What:** the frozen WHY. The thesis: operating systems assumed ONE actor per user; a user now runs N semi-autonomous agents, so the OS's principal abstraction (the process, owned by one trusted human) has no answer — Skyra's principal abstraction becomes the **bounded, auditable agent**. The move is **coupling, not invention** (permissions and spec/plan negotiation exist; welding them *into* the execution model as real graph edges is the contribution). Five observed grips (skills re-read every turn with zero tool-coupling; re-derivation burns the same inference/money; plan mode is an ignorable checklist; bash = ambient authority + illegible audit; you cannot hand-track 5+ agents) collapse to **three invariants**: (I) **compiled, memoized cognition = engrams**, not re-read markdown (THINK compiles once, ACT runs, REMEMBER persists); (II) **the plan is a TYPED CONTRACT**, deviation surfaces as a fault (untyped drift made impossible, not deviation forbidden); (III) **capability-bounded authority + structural provenance + ONE list, the Horizon** (what an agent can't touch is the horizon's complement; across N agents the only composed question is where two overlap = set-intersection). The loop is THINK (propose contract → engrams) / ACT (a JIT — model present at compile and on deopt, model-free on the warm run) / USER (accepts/denies → renegotiate); FAULT = the world returns a new type → guard trips → deopt. *"Recurrence is the resource":* the Nth run is *both* cheaper and safer — one property that accrues.
- **Key artifacts:** `grips-and-invariants.md` (repo root). Companion late summaries: `2026-09-06-what-skyra-is...`, `2026-09-07-consolidation-port-entity-host-and-engram-identity`, `2026-09-08-the-main-loop-and-execution-boundaries`.
- **State:** MOTIVATION (frozen). Names the era's own risk — "a thesis that kept MOVING (v7→v12), so the code never got a still target" — and freezes it. Next step: the CTU inner core is "mid-clean," the THINK/ACT split is downstream; the next thesis revision should come "from the COMPILER fighting back, not from a nicer ontology."

## Throughlines — what survived every rewrite

Four eras, ~20,000 lines deleted twice, and yet a handful of ideas persist under changing names. These are the load-bearing convictions the project keeps re-discovering:

1. **The user/system authority split.** `Jarvis` (user space) vs `Stark` (system space) in v.02 → `Pathos`/`Logos` in v.04 → inner `Think` / outer `Act` in v.05 → **USER / kernel** and the THINK/ACT/USER loop in the grips thesis. The names change; the boundary between "whose intent this is" and "who is allowed to act" never leaves.
2. **Only the world settles claims.** The v.01 kernel maxim ("a command is not trusted because a model emitted it") → dna-v3's epistemic boundary (the model proposes, deterministic parsers compare, only world-derived observations settle) → prediction-falsifiability → **invariant II** (the plan is a type; the world violating it is a fault). The model is never its own judge.
3. **Capability-bounded authority.** Shards-as-capabilities (Mar) → v10 `acquire`/`BOUND`/`MINT` → v11's user-carried horizon verified offline → **invariant III** (the Horizon, one list). Authority is minted, never assumed; a desire does not authorize itself.
4. **Compile once, run many.** Predictive memory + observational store (Mar) → REMEMBER + engrams → v11's Body/Context cold/hot split → **invariant I** (compiled, memoized cognition). A decision should outlive the inference that made it.
5. **One primitive, recursively applied.** metaxu's `Signal` → v.05's `Reality`/`Relation` → the CTU's `Move`. The system keeps collapsing toward a single wire envelope that carries everything.

And the method itself is a throughline: **every generation is built to be thrown away.** The `boundary-crossings.md` / `claude-ideas.md` discipline (docs win over code; mark which shapes are proposals vs. canon) makes each build a probe whose job is to reveal where the interfaces don't hold, then feed the next. The distillations aren't failures recovered from — they're the intended output of the search.

## Where it stands (2026-09-08)

The current core (`skyra-dna-v14`) is a working, race-tested, ~890-line Invoke/Return execution loop with capability inheritance and source-bound returns — the smallest honest version of the executor half of the thesis. The thesis itself (`grips-and-invariants.md`) is frozen for the first time in the project's history. The next build named by that freeze: make the **kernel the first real driver**, with the possibility (a "process") as the unit the kernel's table holds — THINK, ACT, and the human interface each a possibility, the kernel injecting horizon at each possibility's boundary, and every possibility returning only to the human. The loop runs; the next question is whether the compiler half can be made to fight back.

# Skyra DNA v3

This package is the active Skyra cognition experiment. It retains observations, activation,
expression history, predictions, comparisons, interpretation claims, and learned edges.

The central boundary is epistemic:

- the model may propose interpretations, predictions, and actions;
- deterministic parsers compare predictions with eligible observations;
- only world-derived observations settle durable claims;
- unknown and void are not false;
- interpretation and action consequence keep separate falsification paths.

World implementations and transport do not belong here. The package should depend on
explicit observations and affordance contracts rather than device-specific behavior.

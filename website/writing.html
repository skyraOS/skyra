Section C · Design notes

How it was reasoned out.

  • Procedures

    Self-extension: a trace that already ran is remembered as a procedure, run by an interpreter actor the kernel never knows about. A Boundary grows only by composition.

  • The room

    Authority derived from state and proposal. A Boundary is an execution context, shared unless narrowed; faults climb to whoever can grant.

  • A Boundary is a process

    The Boundary is the process; OS processes are its workers.

  • Types by origin, and routes

    The runtime computes types; models write routes at a novelty interrupt. Superseded by Procedures.

  • Crossing the boundary

    The questions every new crossing of the trusted boundary has to answer.

  • The public Boundary

    Ingress from strangers, read-only: no model, no interpreter, nothing that writes.

  • The sky dreams

    The desktop sky as a projection of the record tree: every pixel derived from a record.

  • The controller, package by package

    Every design decision mapped to the line that implements it.

# Praxis Ground — decisions recorded ahead of the spec

**Date:** 2026-07-12 · **Status:** DECISION RECORD (the Praxis spec is not yet
written; these are the calls already made that it must honor)

The action side — Maxim, Effect, emission mechanics — remains deferred and is
gap #1 in [docs-map.md](../../../docs-map.md). This file collects the decisions
that precede it, so they aren't rediscovered or accidentally contradicted.

## 1. A completed action is a Material/Formal cause (decided 2026-07-12)

> A completed action is a formal/material cause. Skyra emits. It's recorded as
> a base node cause.

When Skyra emits an action and it completes, the completed action is persisted
as an **ordinary base `CausalNode`** — one summary cell carrying the clean
sentence, anchored to an immutable semantic birth subgraph. The same one-type
shape as everything else in the graph. No action store, no special action node
kind.

What this settles:

- **A completed action is situation-stuff.** Once it has happened, it is part
  of what the present *is* — Material/Formal reality — not a floating
  intention. It enters the graph the way any happened thing does.
- **Role stays perspectival** (invariant: roles are read from edges relative to
  the active node). The same completed-action node is Material/Formal from
  within its own frame, and citable as **Efficient** from a successor present's
  perspective — "what brought this about" naturally includes "what I just did."
- **Its Final cause is birth-stamped** per the decided self-half of ledger
  item 11: the final cause of Skyra's own action is *the final cause of
  everything that is efficient within the frame* — the action inherits its
  purpose from what was live in the frame that produced it.
- **The `KindAction`/`ActionRecord` deprecation target is now known.** Reform
  §3's proposal/invocation chains are superseded shapes; the migration target
  for a completed action is this base `CausalNode`. Future self-grading grades
  the action node's edges, not a special record.

Open (for the Praxis spec, not decided here):

- **Mint timing** — at emission, at completion, or mint-at-emission +
  confirm-at-completion. "Completed" is the condition in the decision;
  reafference is the natural completion signal (`classify` already routes the
  world's reply to Skyra's own act).
- **Provenance stamp** — the action was composed (Skyra authored it) but its
  completion is observed (the reafference confirms it happened). Whether a
  completed action stamps `composed`, `observed`, or needs the distinction
  drawn finer is undecided.
- **Incoming Final stamping** (item 11's other-agent half) remains open and is
  untouched by this decision.

## 2. Standing candidates the Praxis spec walks (not yet decided)

- **Predictions are Final beliefs.** A self-prediction is plausibly an
  ordinary Final-cause belief about one's own action — which would collapse
  the legacy self/other predict-grade spine into the causal graph's existing
  machinery.
- **Final closes by retrospective citation** — the candidate rule the
  read-only closure reporter exists to test against live runs.
- **Reward vs grade** — whether an action-side reward signal is a distinct
  quantity or another conflation to remove.

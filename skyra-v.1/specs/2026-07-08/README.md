# 2026-07-08 Architecture Set

**Status:** INDEX · updated 2026-07-11

This directory contains one accepted evidence-side model, its kernel/runtime
parents, migration backlog, and historical/deferred Praxis material.

## Canonical Reading Order

1. [Schema / Aitia / Maxim / Evidence](./schema-aitia-maxim-evidence.md) —
   canonical immutable cognitive graph, composition, Evidence ownership, signed
   edge grading, sequential error propagation, and deferred Praxis boundary.

2. [Directed Affordance Invocation](./directed-affordance-invocation.md) —
   canonical invocation/result topology and observation/intervention distinction.

3. [Proportional Amplitude Allocation](./proportional-amplitude-allocation.md) —
   canonical absolute-magnitude allocation with separately carried polarity.

4. [Space / Kernel Interface Reform](./space-kernel-interface-reform.md) —
   `Spacetime`, `Space`, token cost, context-budget amplitude, affordability,
   Slice active state, and active-state history.

5. [DAG / Kernel Responsibility Boundary](./dag-kernel-responsibility-boundary.md) —
   worker lifecycle, Scheduler/Board ownership, multi-wave grading episodes, and
   cascade termination.

## Migration And Historical Documents

- [Cause And Effect Research](./cause-and-effect/) develops query-by-subgraph,
  Effect prediction, and an AIMD token-budget controller for retreat into
  abstraction. It is a candidate revision and does not yet supersede the
  accepted evidence-side model.

- [Hylomorphic Subgraph And Causal Bounds](./hylomorphic-subgraph-and-causal-bounds.md)
  is a research draft exploring a possible collapse of Material and Formal Cause
  into one subgraph, with Efficient/Final causes and occupancy as external bounds.
  It does not yet supersede the accepted evidence-side model.

- [Outstanding Reform Tracks](./outstanding-reform-tracks.md) is migration
  backlog. Legacy `self`/`other`, `KindAction`, and compatibility shapes are not
  canonical architecture.

- [Aitia Maxim Telos Schema Praxis](./aitia-maxim-telos-schema-praxis.md) is
  partially superseded. Its philosophical separation thesis and deferred Praxis
  ideas remain useful; its evidence-side data model must not be implemented.

- [Open Items We Need Settled](./open-items-we-need-settled.md) is a resolved
  index pointing to canonical owners. It contains no independent architecture.

## Scope Boundary

The evidence-side model is accepted for implementation. The following remain a
separate future Praxis specification:

```text
Maxim selection for action
Skyra intervention grading
world-result reafference
Telos progress
reward and utility
action obedience
```

No implementation in this architecture set should invent those mechanics ad
hoc.
